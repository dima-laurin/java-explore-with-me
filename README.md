## Описание проекта

**Explore With Me** — приложение, которое позволяет пользователям делиться информацией об интересных событиях и находить 
компанию для участия в них.

Проект состоит из двух основных сервисов:

- **main-service** — основной сервис приложения, содержащий бизнес-логику и REST API.
- **stats** — сервис статистики, отвечающий за сохранение информации о просмотрах и получение статистики по событиям.

Основной сервис организован по функциональным областям. Для пользователей, событий, категорий, заявок, подборок и комментариев выделены отдельные пакеты, содержащие связанную с ними бизнес-логику, DTO, контроллеры, репозитории и модели.

### Основная функциональность

Приложение позволяет:

- создавать и управлять пользователями;
- создавать, редактировать и публиковать события;
- выполнять поиск и фильтрацию опубликованных событий;
- управлять категориями событий;
- отправлять и обрабатывать заявки на участие;
- создавать и редактировать подборки событий;
- учитывать количество просмотров событий через отдельный сервис статистики;
- создавать, модерировать и оценивать комментарии к событиям.

## Комментарии

В приложении реализована возможность оставлять комментарии к опубликованным событиям.

Основные возможности:

- пользователь может создать комментарий к опубликованному событию;
- новый комментарий создаётся в статусе `PENDING`;
- администратор может подтвердить комментарий (`CONFIRMED`) или отклонить его (`REJECTED`);
- в публичном API отображаются только подтверждённые комментарии;
- автор может просматривать, редактировать и удалять свои комментарии;
- после редактирования комментарий повторно отправляется на модерацию;
- администратор может просматривать комментарии, ожидающие модерации;
- администратор может изменять статус или удалять комментарии;
- пользователи могут ставить подтверждённым комментариям реакции `LIKE` и `DISLIKE`;
- повторная установка той же реакции удаляет её;
- установка другой реакции заменяет предыдущую.

### API комментариев

```text
POST   /users/{userId}/events/{eventId}/comments
       Создание комментария

PATCH  /users/{userId}/comments/{commentId}
       Редактирование комментария автором

DELETE /users/{userId}/comments/{commentId}
       Удаление комментария автором

GET    /users/{userId}/comments
       Получение комментариев пользователя

GET    /events/{eventId}/comments
       Получение подтверждённых комментариев события

PUT    /users/{userId}/comments/{commentId}/reaction
       Добавление, изменение или удаление реакции

GET    /admin/comments
       Получение комментариев для модерации

PATCH  /admin/comments/{commentId}
       Изменение статуса комментария администратором

DELETE /admin/comments/{commentId}
       Удаление комментария администратором
```
